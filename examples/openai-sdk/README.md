# OpenAI SDK (Node.js)

```bash
cp .env.example .env   # optional; or export vars in the shell
# edit .env — set ROUTERA_API_KEY from https://routera.ai

npm install
export ROUTERA_API_KEY="sk-..."   # if not using a dotenv loader
npm start
```

`baseURL` is `https://api.routera.ai/v1`. Pick `ROUTERA_MODEL` from live `/v1/models`.
